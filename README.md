### 📌 Featured Projects

#### 🔌 [ansible-pihole](https://github.com/LaTola/ansible-pihole)
Self-hosted DNS resolution stack provisioned with Ansible: **Pi-hole** for network-wide filtering in front of **Unbound** as a local recursive resolver, plus UFW, time sync, log rotation, and maintenance cron jobs. Originally deployed on a Raspberry Pi, now running on an Orange Pi Zero 3 (Armbian), and distro-agnostic across Debian/Ubuntu.

`Ansible` `Jinja` `Shell` `Pi-hole` `Unbound` `ARM64`

#### ☁️ [CP2 — Infrastructure as Code on Azure](https://github.com/LaTola/CP2)
End-to-end IaC project: **Terraform** provisions the Azure resources (VNet, VM, NSG, Container Registry, AKS cluster), while **Ansible** configures the services — a Podman-run Nginx server with SSL and basic auth, and a Grafana deployment on AKS.

`Terraform` `Ansible` `Azure` `AKS` `Podman` `Grafana`

#### 🇺🇾 [digito_cedula](https://github.com/LaTola/digito_cedula)
A Python library and CLI that calculates the check digit for Uruguayan *Cédula de Identidad* numbers — handles multiple input formats, validates length, and ships with unit tests (playground project abandoned).

`Python` `CLI` `Unit Testing`

#### 🚀 [CP1 — Serverless ToDo API](https://github.com/LaTola/CP1)
A RESTful ToDo API built with **AWS SAM** and Lambda, with **Jenkins** pipelines driving CI/CD across staging and production stacks, and local DynamoDB support for offline development.

`AWS SAM` `Lambda` `Jenkins` `Python` `DynamoDB`

#### ⚡ [Python-API-Development](https://github.com/LaTola/Python-API-Development)
A CRUD REST API built while working through a FastAPI course — **FastAPI** + **SQLAlchemy** + **Alembic** migrations, served with Uvicorn/Gunicorn, with notes on deploying to Heroku.

`FastAPI` `SQLAlchemy` `Alembic` `Python`
